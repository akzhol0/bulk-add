# Coursera Bulk Course Adder

Скрипт добавляет один курс в коллекцию
`Қазақстандық университеттердің курстары / Курсы казахстанских вузов`
во всех программах из `programs.json`.

`programs.json` сформирован из загруженного Excel-файла: 100 программ, у каждой есть уникальный slug.

## 1. Требования

- Windows/macOS/Linux
- Node.js 20+ (рекомендуется LTS)
- Google Chrome
- права администратора Coursera для этих программ

## 2. Установка

Откройте терминал в этой папке и выполните:

```bash
npm install
```

## 3. Первый вход в Coursera

```bash
npm run login
```

Откроется отдельный Chrome-профиль. Войдите в Coursera вручную, включая SSO/MFA, затем вернитесь в терминал и нажмите Enter.

Профиль `.playwright-profile` содержит вашу авторизованную сессию. Не отправляйте эту папку другим людям и не добавляйте ее в Git.

## 4. Безопасный тест на одной программе

Сначала проверить Astana IT University без фактического добавления:

```bash
npm run add -- --slug=university-26-y4lco --dry-run
```

Скрипт должен пройти:

1. Программа
2. Каталог
3. Коллекции
4. `Қазақстандық университеттердің курстары / Курсы казахстанских вузов`
5. Добавить материалы
6. Поиск `Адам және жануарлар физиологиясы`
7. Найти карточку курса
8. Остановиться, ничего не добавляя

## 5. Реальный тест на Astana IT University

```bash
npm run add -- --slug=university-26-y4lco
```

## 6. Запуск на всех 100 программах

```bash
npm run add
```

По умолчанию используется курс из `config.json`:

`Адам және жануарлар физиологиясы`

Для другого нового курса можно не менять файл, а передать название командой:

```bash
npm run add -- --course="Точное название нового курса"
```

## 7. Отчеты и ошибки

- Каждый запуск добавления: `reports/ДОБАВЛЕНИЕ_дата-время/`
- Каждый запуск аудита: `reports/АУДИТ_дата-время/`
- Excel-отчёт: `report.xlsx`
- Полный UTF-8 лог консоли: `console.txt`
- Скриншоты ошибок: подпапка `screenshots/` внутри соответствующего запуска

Excel-отчёт добавления содержит количество курсов в целевой коллекции до и после обработки:
`collection_courses_before` и `collection_courses_after`.

Статусы:

- `success_verified` — добавление подтверждено, курс найден в коллекции
- `success_submitted` — Coursera приняла подтверждение, но дополнительная проверка списка не увидела курс в текущем DOM
- `already_exists` — курс уже был в коллекции
- `dry_run_ok` — курс найден в безопасном тестовом режиме
- `error` — ошибка; сохраняется скриншот

## 8. Проверка всех курсов и провайдеров

Эталон берётся из файла `All courses.xlsx` в корне проекта:

- столбец A — точное название курса;
- столбец B — точное название провайдера;
- первая строка — заголовки.

Проверить все программы (только чтение):

```powershell
npm run audit
```

Проверить одну программу:

```powershell
npm run audit -- --slug=university-26-y4lco
```

Проверить первые три программы:

```powershell
npm run audit -- --limit=3
```

Аудит не открывает `Add content` и ничего не добавляет. Результаты сохраняются в отдельной папке
`reports/АУДИТ_дата-время/`: Excel-отчёт `report.xlsx` и UTF-8 лог `console.txt`.

## 9. Создание коллекций из Excel по ссылке на программу

Каждая вкладка Excel-файла становится отдельной коллекцией. Название коллекции берётся из названия
вкладки, а точные названия курсов — из столбца `Онлайн-курсы Coursera`. Имя самого Excel-файла
не используется как название программы.

Excel ограничивает название вкладки 31 символом. Полные варианты таких названий указываются в
`collection-names.json` в формате `"обрезанное название вкладки": "полное название коллекции"`.
Если вкладка содержит ровно 31 символ и сопоставления нет, скрипт выведет предупреждение и продолжит
с названием вкладки как есть. Для отдельного файла сопоставлений можно передать `--names="имя.json"`.

Безопасная проверка Excel и уже существующих коллекций без создания:

```powershell
npm run create-collections -- --url="ССЫЛКА_НА_КАТАЛОГ" --file="ИМЯ_ФАЙЛА.xlsx" --dry-run
```

Создать только первую коллекцию для реальной проверки:

```powershell
npm run create-collections -- --url="ССЫЛКА_НА_КАТАЛОГ" --file="ИМЯ_ФАЙЛА.xlsx" --limit-collections=1
```

Создать все коллекции из всех вкладок:

```powershell
npm run create-collections -- --url="ССЫЛКА_НА_КАТАЛОГ" --file="ИМЯ_ФАЙЛА.xlsx"
```

Скрипт оставляет описание пустым и не меняет High stakes или другие настройки. Если коллекция с
точным названием уже существует, она полностью пропускается. Если точный курс не найден, остальные
курсы всё равно обрабатываются, а пропуск записывается в отчёт.

После обработки скрипт поднимает перечисленные в Excel коллекции наверх. Их итоговый порядок
совпадает с порядком вкладок Excel; старые коллекции остаются ниже.

Повторить только сортировку, не создавая коллекции и не обрабатывая курсы:

```powershell
npm run create-collections -- --url="ССЫЛКА_НА_КАТАЛОГ" --file="ИМЯ_ФАЙЛА.xlsx" --reorder-only
```

Результаты сохраняются в `reports/СОЗДАНИЕ_КОЛЛЕКЦИЙ_дата-время/`: `report.xlsx`, UTF-8
`console.txt` и скриншоты ошибок.

## Важное ограничение

Селекторы построены по интерфейсу и скриншотам Coursera, а не по реальному DOM страницы. Поэтому первый `--dry-run` на одной программе обязателен. Если Coursera использует другие ARIA-роли/HTML-структуру для карточки курса, потребуется один небольшой селекторный патч по результату первого запуска.
